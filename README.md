# KROMA Studio — Limited-Edition Design Objects & Curated Gallery

> Bridging digital chromatic fluidity and tactile fine craftsmanship.

KROMA Studio is an architectural digital gallery showcasing limited-edition physical design artifacts. The platform integrates hand-blown Kyoto borosilicate glass, Seville reactive reduction earthenware, and Lyon jacquard mulberry silk tapestries into a museum-grade web experience.

---

## Key Features & Interactive Architecture

- **In Situ Architectural Staging**: Interactive lookbook displaying artifacts across Swiss alpine salons, Kyoto machiya courtyards, and Lyon industrial lofts.
- **Lighting Temperature Simulator**: Experience the optical refractions and glaze reactions under Daylight (5500K), Golden Hour (3200K), and Evening Gallery lighting (2700K).
- **Scale & Spatial Fitting Studio**: Compare physical dimensions and weights with a live toggle between Imperial (Inches / Lbs) and Metric (Centimeters / Kg) with recommended viewing distances.
- **The Craft Laboratory**: Real-time technical telemetry badges detailing 1,220°C Cone 6 reduction curves, 1.473 optical refraction dispersion, and 320 threads/dm silk jacquard coordinate matrices.
- **Verified Collector Testimonials & Provenance**: Filterable collector reviews, 4.98/5.0 aggregate rating, international press recognition (*Architectural Digest*, *Wallpaper\**, *Frame Magazine*, *Elle Décor*).
- **Institutional Exhibitions Timeline**: Documentation of gallery shows and biennales in Milan, Kyoto, Basel, and Venice.
- **Private Atelier Desk**: Interactive booking concierge for custom glaze flows, architectural dimensions, and private salon appointments.
- **Full E-Commerce Flow**: Real-time search, category filtering, responsive cart drawer, promo codes (`KROMA10`), wishlist archive, and checkout modal.

---

## Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 with custom design tokens (`Cormorant Garamond`, `Inter`)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Code Quality**: Oxlint
- **Deployment**: Vercel
